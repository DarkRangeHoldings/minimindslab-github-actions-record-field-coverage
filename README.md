# Record Field Coverage

Report how many records in a JSON array have a given field present, missing, or null.

Generated by MiniMindsLab 02.13 GitHub Action Factory.

## Usage

```yaml
- uses: ./path-to-action
  id: miniminds
  with:
    payload: '{"records":[{"sku":"A","qty":1},{"sku":"B"},{"sku":"C","qty":null}],"field":"qty"}'
- run: echo '${{ steps.miniminds.outputs.result }}'
```

Runtime: Node 24. No external dependencies. No network access.
